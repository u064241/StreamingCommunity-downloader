# StreamingCommunity Downloader 2.8.3

This release adds the first complete Italian/English interface pass and improves the
catalogue presentation and update notifications.

## Italian / English interface

- Automatic language selection from the browser/Windows locale, with persistent manual
  IT/EN buttons and dynamic switching without losing form values.
- Translated login, navigation, search, catalogue, title detail and settings screens.
- Centralised translation helper with Italian fallback for messages not yet localised.

## Interface improvements

- Update-check toasts are moved to a fixed, highly visible area above the catalogue.
- Stronger catalogue-card hover zoom and elevation.
- Search placeholders, buttons and common dialogs follow the selected language.

## Included homepage and catalogue features

- **Coming soon** section and progressively loaded genre shelves.
- **Browse all** buttons open the paginated catalogue for a shelf or genre.
- Film/TV filters, linkable navigation and a return-to-home button.
- Badges for unavailable titles and upcoming seasons.
- Domain-specific caching, retries for unavailable sections and protection against stale responses.

## Publishing and documentation

- README features updated to describe the catalogue.
- Documented release workflow: tests, README, release notes, version and commit.
- Publishing stops before compilation if there are uncommitted changes, an existing release/tag,
  missing release notes or a failure to verify GitHub.
- GitHub release notes are read from the version-controlled release notes file.

## Packages and limitations

- Installer with Install/Portable modes and a portable ZIP, with a manifest and SHA-256 checksums.
- Optional verified SoftEther VPN Client installer bundle, with local installation, official
  Windows x64 release checks and application-side download of the selected official installer.
- Long catalogue titles wrap inside their cards instead of being truncated.
- User updates are provided by the u064241 fork.
- Title and genre availability depends on the source website and may change.
- Browser verification of every translated page and modal remains recommended before
  distributing the package.
