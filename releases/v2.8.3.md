# StreamingCommunity Downloader u064241 2.8.3

This release updates the documentation and makes release notes a required part of the
publishing process. It includes the expanded homepage introduced in version 2.8.2.

## Included homepage and catalogue features

- **Coming soon** section and progressively loaded genre shelves.
- **Browse all** buttons open the paginated catalogue for a shelf or genre.
- Film/TV filters, linkable navigation and a return-to-home button.
- Badges for unavailable titles and upcoming seasons.
- Domain-specific caching, retries for unavailable sections and protection against stale responses.

## Publishing and documentation

- README features updated to describe the catalogue.
- Documented release workflow: tests, README, release notes, version and commit.
- Publishing stops before compilation if there are uncommitted changes, an existing release/tag,
  missing release notes or a failure to verify GitHub.
- GitHub release notes are read from the version-controlled release notes file.

## Packages and limitations

- Installer with Install/Portable modes and a portable ZIP, with a manifest and SHA-256 checksums.
- User updates are provided by the u064241 fork.
- Title and genre availability depends on the source website and may change.
- Full desktop/mobile visual verification of the new homepage is still pending.
