# StreamingCommunity Downloader u064241 2.8.3

Questa release aggiorna la documentazione e rende le note delle novita una parte obbligatoria
del processo di pubblicazione. Include la homepage ampliata introdotta nella versione 2.8.2.

## Homepage e catalogo inclusi

- Sezione **In arrivo** e righe per genere caricate progressivamente.
- Pulsanti **Sfoglia tutti** per aprire il catalogo paginato di una sezione o di un genere.
- Filtri Film/Serie TV, navigazione tramite URL e ritorno alla homepage.
- Indicatori per titoli non ancora disponibili e nuove stagioni in arrivo.
- Cache distinta per dominio, retry delle sezioni non disponibili e protezione dalle risposte tardive.

## Pubblicazione e documentazione

- Features del README aggiornate con le funzioni del catalogo.
- Procedura di release documentata: test, README, note, versione e commit.
- Pubblicazione bloccata prima della compilazione in presenza di modifiche non committate,
  release/tag gia esistenti, note mancanti o impossibilita di verificare GitHub.
- Le note pubblicate su GitHub provengono dal file versionato della release.

## Pacchetti e limiti

- Installer con scelta Installazione/Portable e ZIP portable, con manifest e checksum SHA-256.
- Gli aggiornamenti degli utenti provengono dal fork u064241.
- La disponibilita di titoli e generi dipende dal sito sorgente e puo cambiare.
- La verifica visiva completa desktop/mobile della nuova homepage resta da completare.
