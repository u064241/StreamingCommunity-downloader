## Changes

- Source protection: an hourly request budget, automatic backoff after 403, 429, 503 or segment
  pushback, a separate allowance for artwork, a global connection cap, and performance presets
  with Conservative as the default. Repeated pauses in one hour switch the panel to Conservative.
- Hardware diagnosis on demand: it reads CPU, memory, GPU/VRAM and verified encoders, then writes
  the conservative preset that matches this machine.
- Artwork: posters and backdrops are kept in an in-memory cache. Settings > Source has a
  "Refresh posters" button that clears the image cache and the listing caches.
- Front page shelves, search, title details and an Archive page. Archive pages load only when you
  open them or change a filter.
- Shelf arrows are larger and appear on every row that can scroll, not only the first one.
- "All sources" is the default search mode at startup. Its start page shows the StreamingCommunity
  front page, and typed searches cover every source.
- Hovering a card zooms it without playing a trailer, and without asking the source for
  extra details.
- The source-pause banner on the Downloads page is gone. The automatic protection is unchanged:
  the queue still holds after a refusal.
- RaiPlay as a metadata-only source: titles, shelves and search. Downloads are refused by design.
- SoftEther/VPN Gate: the manager can be opened, hidden to the tray, or closed. Profiles are
  created by hand or from the VPN Gate list. The panel never starts a VPN connection by itself.
- When the source refuses requests from this IP, the panel shows a notice that suggests using the
  VPN. Checking the public IP happens only on your click.
- The panel stops itself about 3 seconds after the last browser tab is closed (Windows desktop,
  local address).
- Domain changes: retired domains are never adopted again. Telegram domain auto-apply can be
  turned off in Settings.
- Removed: Jellyfin login, multiple users, and the followed-series list. The panel is single-user
  and local; the library folder remains.

## Notes

- This build replaces the earlier 2.8.1 release published on 2026-11-08 under the same version
  number. The version is not yet a stable base: later releases will move from here.
- The panel is for local, single-user use. Do not expose it to a network.
- Restart the panel after updating; static files are versioned per process.
- Use the source responsibly: the defaults are chosen to reduce the risk of an IP block.
