## Changes

- This is the first public release of the fork after the upstream `2.8.0` baseline.
- Added the bilingual Italian/English interface and improved catalogue presentation.
- Added progressive catalogue shelves, genre browsing, title details and hover previews.
- Added portable update checks, installer/portable distribution and Windows registration.
- Added the optional SoftEther/VPN Gate flow with progress, server discovery and manual
  profile creation; connections are never started automatically.
- Added on-demand hardware diagnostics for CPU, memory, GPU/VRAM and verified encoders,
  with conservative recommendations for downloads and conversions.

## Notes

- This release is the new public baseline of the `u064241` fork.
- The setup includes the installer and portable modes; no separate portable ZIP is
  published.
