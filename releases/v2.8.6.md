# StreamingCommunity Downloader u064241 2.8.6

## Interface

- Cast and director names now open a web search in a new browser tab when clicked.
- The cast search action is handled explicitly by the frontend so it is not intercepted by
  panel navigation.

## Portable Windows

- Retains the portable registration flow in Windows Installed apps, with the folder-local
  uninstaller preserving settings, databases and downloads.

## Notes

- The release is published by the `u064241` fork and includes the Windows installer, portable ZIP,
  update manifest and SHA-256 checksums.
