# StreamingCommunity Downloader u064241 2.8.4

## Windows portable integration

- Portable mode in Setup now adds a separate entry to Windows Installed apps, backed by the
  existing folder-local uninstaller. The regular installed edition keeps its own entry.
- Portable ZIPs register on first launch for the current user, without administrator rights.
  The generated uninstaller removes known program files and preserves settings, databases and downloads.
- Each portable folder has its own registration, allowing separate copies to coexist.

## Interface

- The panel version is displayed prominently in the page header and sidebar, including on mobile.
- Secondary text, muted labels and input placeholders have higher contrast across the dark interface.
- Floating up/down arrows jump to the top or bottom of long pages, with keyboard accessibility
  and support for reduced-motion preferences.
- **Browse all** buttons are highlighted on the existing homepage shelves, Coming soon and genre
  shelves. They open the internal paginated catalogue with film/TV filters.

## Release maintenance

- English README and release notes updated together with the version.
- After publishing, package retention keeps the latest two stable GitHub releases and preserves
  older tags and release notes. Local package retention remains under the user's control.

## Notes

- Close all panel tabs and wait for downloads to finish before uninstalling a portable copy.
- Portable ZIP registration applies to the folder's current location; uninstall the old copy
  before moving it and launch the new copy at its final location.
- Source website sections and title availability can change independently of this application.
